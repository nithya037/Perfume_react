# 🌸 Perfume React – E-Commerce Website

A responsive and modern **Perfume E-Commerce Website** built using React.js. This project showcases perfume products with reusable React components, a search bar, and an attractive user interface.

## 🚀 Features

- Responsive and modern user interface
- Reusable React components
- Navigation bar
- Product display section
- Product images and pricing
- Search functionality
- Buy Now buttons
- Footer section

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Vite

## ⚙️ Installation & Setup

**1. Clone the Repository**

```bash
git clone https://github.com/nithya037/Perfume_react.git
```

**2. Navigate to the Project Folder**

```bash
cd Perfume_react/my_app
```

**3. Install Dependencies**

```bash
npm install
```

**4. Run the Development Server**

```bash
npm run dev
```

**5. Open in Browser**

```text
http://localhost:5173/
```

## 🎯 Project Purpose

The main objective of this project is to practice React.js fundamentals, component-based architecture, JSX, and CSS styling by developing a simple perfume shopping website.
